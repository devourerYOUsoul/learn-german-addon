# Deutsch im Spiel (NeoForge 1.21.1, клиентский мод)

Что делает:
- под названием предмета в подсказке показывает немецкое слово с артиклем (der — голубой, die — красный, das — зелёный);
- после еды, питья, крафта и плавки открывает окно: нужно написать предложение по-немецки
  (например «Ich esse den Apfel.»). Умляуты можно заменять: ä = ae, ö = oe, ü = ue, ß = ss.

Файлы, которые мод создаёт в папке `config` игры:
- `deutschimspiel-client.toml` — настройки (пауза между окнами, время `PRESENT`/`PERFECT`, шанс окна);
- `deutschimspiel-missing.txt` — предметы, для которых нет немецкого слова (пришли мне этот файл);
- `deutschimspiel-words.json` — твои собственные слова (формат как в `words.json`), создаётся вручную;
- `deutschimspiel-progress.json` — статистика.

Формат слова: `"id_предмета": ["Wort", "m|f|n|p"]`. Пятый-шестой элементы — другое слово для предложений,
например `"milk_bucket": ["Milcheimer","m","Milch","f"]`.

Сборка: загрузи все файлы в репозиторий на GitHub, открой вкладку Actions, дождись зелёной галочки,
скачай артефакт `deutschimspiel-jar` и положи jar в папку mods.
